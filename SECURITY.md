# Security policy

## Reporting a vulnerability

Report vulnerabilities privately, never in a public issue or pull request:

- GitHub: [open a private security advisory](https://github.com/OctopiAI/better-enrollment/security/advisories/new)
- Email: [talat@octopi.ai](mailto:talat@octopi.ai)

Include the affected version, your Better Auth version and configuration, and steps to reproduce. You will get an acknowledgement within three business days. Fixes are released before the details are published, and reporters are credited unless they prefer otherwise.

## Supported versions

Security fixes go to the latest minor release of the current major version. Upgrading to it is the supported way to receive them.

## Scope

The plugin's own guarantees are listed on the [Security](https://better-enrollment.octopi.ai/docs/security) page, together with what an application must still do itself. A report that one of those guarantees does not hold is in scope.
